

Let's do a 15-minute revision of everything we've learned about strings. No long explanations—just the key ideas.

📚 Python Strings - Revision Sheet
1️⃣ String

A string is a sequence of characters.

name = "Aimen"
2️⃣ Indexing

Access one character.

name[0]

Output:

A

Negative indexing:

name[-1]

Output:

n
3️⃣ Slicing

General syntax:

string[start:stop:step]

Examples:

name[0:3]
Aim
name[:]

Copies the whole string.

name[::-1]

Reverses the string.

4️⃣ Strings are Immutable

❌ Not allowed:

name[0] = "B"

✅ Allowed:

name = "Bilal"
String Methods
5️⃣ upper()
name.upper()
AIMEN
6️⃣ lower()
name.lower()
aimen
7️⃣ strip()

Removes spaces from the beginning and end.

"  Python  ".strip()
Python
8️⃣ replace()
text.replace("Python","Java")
9️⃣ find()

Returns the index.

text.find("Python")

Returns:

0

If not found:

-1
🔟 count()

Counts occurrences.

text.count("a")
1️⃣1️⃣ startswith()
text.startswith("Py")

Returns:

True
1️⃣2️⃣ endswith()
text.endswith(".py")

Returns:

True
split() and join()
1️⃣3️⃣ split()

One String ➜ Many pieces

text = "I love Python"

words = text.split()

Result:

['I', 'love', 'Python']
1️⃣4️⃣ join()

Many pieces ➜ One String

" ".join(words)

Result:

I love Python
Validation Methods
1️⃣5️⃣ isalpha()

Only letters?

"Aimen".isalpha()
True
"Aimen123".isalpha()
False
1️⃣6️⃣ isdigit()

Only digits?

"123".isdigit()
True
1️⃣7️⃣ isalnum()

Letters + digits only?

"Aimen123".isalnum()
True
"Aimen 123".isalnum()
False
len()

For strings:

len("Python")
6

Counts characters.

For lists:

len(["Python","Java","C++"])
3

Counts items.

⭐ Most Important Things to Remember
Rule 1
split()

One String → List

Rule 2
join()

List → One String

Rule 3
len()

Counts:

characters in a string
items in a list
Rule 4

Strings are immutable.

Lists (next chapter) are mutable.
